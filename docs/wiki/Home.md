## 빠른 시작

| 방법 | 명령 |
|------|------|
| **권장** | `26x86.command` 더블클릭 |
| 마법사 | `python3 -m x86 wizard` |
| CLI | `python3 -m x86 --help` |

```bash
python3 -m x86 detect [--json]
python3 -m x86 build [--model ...]
python3 -m x86 patch [--auto]
python3 -m x86 status
```
